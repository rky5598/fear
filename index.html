Карта страхов

Задание 1-го дня. Пройдите по карточкам — каждый дом это вектор, внутри карточки перечислены страхи одного вида. Отмечайте только те страхи, которые про вас: те, что накрывают, а не те, что «бывает у людей». Можно добавлять свои — по одному, через поле ввода. В конце система определит ваш векторальный профиль и состояние каждого вектора.

Как это накрывает?

Для каждого дома, где вы отметили страхи, выберите — как они обычно вас накрывают. Это определит ступень по лестнице страха и стадию (стресс → фрустрация → невроз).
